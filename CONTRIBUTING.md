\# Contributing to Krishna



Thank you for your interest in contributing to \*\*Krishna — Personal AI Assistant\*\*!



Krishna is an experimental, modular AI assistant project exploring reasoning, memory, voice interaction, research and intelligent task automation. Contributions, ideas, bug reports and constructive feedback are welcome.



\## 1. Before You Start



\- Read the \[README](README.md) to understand the project.

\- Check existing GitHub Issues before starting new work.

\- For major changes, open an issue first to discuss the proposed approach.

\- Keep contributions focused and avoid unrelated changes.



\## 2. Ways to Contribute



You can contribute through:



\- Bug fixes and reliability improvements.

\- AI orchestration and backend improvements.

\- Memory and reasoning development.

\- Voice interaction and speech processing.

\- Desktop interface improvements.

\- New skills, tools and integrations.

\- Documentation and installation instructions.

\- Testing and performance improvements.



\## 3. Development Guidelines



\- Keep code modular and maintainable.

\- Use clear, descriptive names.

\- Follow existing project conventions where practical.

\- Add comments when explaining non-obvious logic.

\- Avoid unnecessary dependencies.

\- Do not commit generated files, model weights or local environment data.



\## 4. Security



\*\*Never commit:\*\*



\- API keys or access tokens.

\- Passwords or application credentials.

\- Personal conversation data.

\- Private configuration files.

\- Browser profiles or authentication sessions.



Use environment variables and a local `.env` file for sensitive configuration. Update `.env.example` when new configuration variables are introduced, without including real credentials.



\## 5. Submitting Changes



1\. Fork the repository.

2\. Clone your fork.

3\. Create a separate branch for your contribution.

4\. Make your changes.

5\. Test the affected functionality where practical.

6\. Commit your changes with a descriptive message.

7\. Push your branch.

8\. Open a Pull Request against the original repository's `main` branch.



Suggested branch names:



\- `feature/voice-improvements`

\- `fix/memory-handling`

\- `docs/setup-guide`



Suggested commit messages:



\- `Add voice interaction improvements`

\- `Fix memory retrieval handling`

\- `Update installation documentation`



\## 6. Pull Request Guidelines



Please include:



\- A clear explanation of the problem or feature.

\- A summary of the changes.

\- Testing performed and any known limitations.

\- Screenshots or logs when relevant.



Keep pull requests focused and avoid submitting unrelated changes.



\## 7. Current Project Status



Krishna is actively evolving. Some components are experimental, and the architecture and installation process are still being consolidated.



Please discuss substantial architectural changes before implementing them.



\## 8. License and Attribution



By contributing, you agree that your contributions will be distributed under the project's \[MIT License](LICENSE).



Please preserve existing copyright and license notices.



\## 9. Community



Be respectful, constructive and collaborative.



Every useful contribution matters, whether it is code, documentation, testing or feedback.
